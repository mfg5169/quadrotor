Quadrotor Project Using Vive Sensor

This project implements real-time embedded control for a quadrotor using a Raspberry Pi and a Vive lighthouse tracking system. A custom IMU (MPU-9250) and joystick interface provide manual overrides and calibration routines.

Components

  • Raspberry Pi
  • MPU-9250 IMU
  • PWM board for ESC control
  • Electronic Speed Controllers and motors
  • HTC Vive lighthouse sensors
  • Joystick or keyboard for user input
  • 5V power system

Control Highlights

  • Complementary filtering to combine gyro and accelerometer readings:
    Rollt = rollaccel × A + (1 - A) × (rollgyroΔ + Rollt−1)
  • IMU calibration averages 1000 samples to zero out bias.
  • Shuts down motors if extreme gyro rates or angles are detected.
  • Keyboard and joystick inputs adjust desired pitch and roll in 0.5° increments.
  • Failsafe logic stops operation on heartbeat timeout or lack of Vive data.
  • Dual–level yaw controllers: one for rate control and another for orientation.

Workflow

  1. Calibrate IMU and Vive tracker.
  2. Start keyboard or joystick control interface.
  3. Command pitch, roll, thrust, yaw and pause/unpause actions.
  4. Autonomous control blends joystick and Vive feedback to maintain stability.
  5. Logs sensor data and motor outputs to CSV for analysis.

The autonomous mode can be overridden by the joystick at any time, blending manual commands with Vive-derived targets.
